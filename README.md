# Block Builder

Cities: Skylines II 코드 모드. 지도에 영역을 그리면, 고른 건물·공원·주차장을 그 안에 "테트리스"처럼 채워 넣고, 필요하면 내부 도로까지 깝니다.

> 상태: 개발 중. 배치 엔진은 단위 테스트(138개)로 검증했고, 게임 안에서는 기본 흐름(영역 → 미리보기 → 적용), 패널, 꼭짓점 맞춤을 확인했습니다. Anarchy 연동·겹침, 리스트 관리, 건물 찾기, 채움 강도, 고유건물 그룹은 아직 게임에서 확인 전입니다. **버릴 도시에서 테스트하세요.**

## 기능

- **영역 선택**: 칠하기(브러시로 자유롭게 칠함, 도로는 벽처럼 칠해지지 않고 경계는 연석에 맞춰짐, 기본) 또는 직접 그리기(꼭짓점 클릭). 짓기는 패널의 [짓기] 버튼(직접 그리기에서는 왼쪽 클릭도 가능). 칠하기 동작은 Placemaker(GPL-3.0)의 동작을 참고해 독자 구현했습니다.
- **영역 채우기**: 고른 영역 안에서 도로를 따라 필지를 연석에 맞추고 앞면이 도로를 보게 배치합니다. 곡선 도로는 연석 곡선을 따라 필지를 돌려 놓습니다. 가중치·최대 개수·시드(배치 섞기) 지원.
- **채울 건물**: 리스트 전체 / 패널에서 체크한 항목만.
- **건물 옮기기**: 미리보기에서 건물을 Ctrl+드래그하면 옮겨집니다(도로에 붙고 도로를 바라봄, 겹치면 빨간색으로 표시되고 놓이지 않음). 처음 옮길 때 나머지 배치는 고정됩니다.
- **내부 도로 생성**: 깊은 영역에 건물 두 줄이 등을 맞대는 간격으로 도로를 깔고, 끝은 기존 도로에 연결, 긴 블록엔 가로 도로 추가. 안 될 때는 필요한 깊이를 숫자로 안내.
- **기존 건물 피하기**, **경계 자동 연석 맞춤**.
- **꼭짓점 맞춤**: 연석·교차로 모서리·도로와 평행/직각·8m 길이 단위. 게임 기본 맞춤 툴바를 빌더 패널 안에 그대로 넣었습니다.
- **게임 내 패널**: 왼쪽 위 버튼 또는 단축키 **Ctrl+Shift+B**(옵션에서 변경 가능). 끌어서 옮길 수 있는 창(위치 기억), 접을 수 있는 칸, 진행 단계와 오류 안내.
- **리스트(프리셋) 관리**: 패널에서 새로 만들기, 체크한 건물로 만들기, 복제, 이름 변경, 삭제, 건물 빼기. 파일은 `ModsData/BlockBuilder/palettes/*.txt` 텍스트 파일이라 직접 고쳐도 됩니다. 처음 실행 시 기본 리스트 2개가 생깁니다.
- **건물 찾기**: 불러온 모든 건물을 이름·구역, 용도, 테마, 최대 필지 크기로 찾아 현재 리스트에 추가(한 번에 최대 300개).
- **고유건물**: 건물 찾기에 "고유건물" 그룹이 있습니다. 게임의 고유 오브젝트(랜드마크 등, `UniqueObjectData`)와 시그니처 건물을 용도와 상관없이 모아 보여줍니다. 게임은 도시에 하나씩만 허용하므로, 리스트에서 개수 제한이 몇으로 적혀 있든 한 번 채울 때 최대 1개만 놓습니다(Anarchy를 켜도 동일). 옵션의 "카탈로그 내보내기" 버튼으로 만든 `catalog.tsv`의 kind 열에서 `Unique`가 붙은 건물을 확인할 수 있습니다.
- **채움 강도**: 여유(필지 사이 4m) / 보통 / 촘촘(2m 단위로 빈틈까지 탐색) / 사용자 지정(필지 사이 간격과 좌우·뒤쪽 겹침을 0.5m 단위로 직접 지정, 겹침은 Anarchy 필요).
- **Anarchy 연동(선택)**: Anarchy가 설치돼 있으면 빌더 도구를 Anarchy에 등록하고, 패널에서 Anarchy를 켜고 끌 수 있습니다. 채움 강도 "사용자 지정"일 때만, 그리고 Anarchy가 켜져 있을 때만 겹침(좌우 0~8m, 뒤쪽 0~16m, 0.5m 단위)이 적용됩니다(도로·앞면은 겹치지 않음).
- 성장형 건물은 Plop the Growables와 함께 쓰는 것을 전제로 합니다.

## 구조

| 경로 | 내용 |
|---|---|
| `Core/` | 게임과 분리된 순수 C# 배치 엔진(배치, 도로 생성, 경계 맞춤, 꼭짓점 맞춤, 카탈로그 분류·필터, 리스트 형식) |
| `Core.Tests/` | xUnit 테스트 (`dotnet test`) |
| `BlockBuilder/` | 게임 연결: 도구(`BuilderTool`), 카탈로그 스캔, 설정·로케일(EN/KO), 패널 바인딩(`BuilderUISystem`), Anarchy 연결, 기술 검증용 Spike 도구 |
| `UI/` | React 패널 (게임 UI 모드 템플릿 기반) |
| `DESIGN.md` | 설계와 검증 기록, 테스트 순서, 남은 일 |

## 빌드

필요: Cities: Skylines II 공식 모딩 툴체인(`CSII_*` 환경 변수), .NET SDK, Node.js 18+.

```sh
cd UI && npm install        # 처음 한 번
cd ../BlockBuilder && dotnet build -c Release
```

`dotnet build`가 모드를 `%LocalLow%\Colossal Order\Cities Skylines II\Mods\BlockBuilder`에 배포하고, 이어서 UI도 빌드합니다(배포 단계가 폴더를 지우기 때문). 게임이 켜져 있으면 DLL이 잠겨 배포가 실패합니다.

엔진 테스트:

```sh
cd Core.Tests && dotnet test
```

## 로그

`%LocalLow%\Colossal Order\Cities Skylines II\Logs\BlockBuilder.log` — 계획 크기, 적용/차단 사유(오류 종류별 개수), Anarchy 연결 상태.
