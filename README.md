# Block Builder

Cities: Skylines II 코드 모드. 지도에 영역을 그리면, 고른 건물·공원·주차장을 그 안에 "테트리스"처럼 채워 넣고, 필요하면 내부 도로까지 깝니다.

> 상태: 개발 중. 배치 엔진은 단위 테스트(57개)로 검증했고, 게임 안에서는 기본 흐름(영역 → 미리보기 → 적용), 지정 배치, 패널, 꼭짓점 맞춤을 확인했습니다. Anarchy 연동·겹침 허용은 아직 게임에서 확인 전입니다. **버릴 도시에서 테스트하세요.**

## 기능

- **영역 채우기**: 꼭짓점을 찍어 다각형을 닫으면, 도로를 따라 필지를 연석에 맞추고 앞면이 도로를 보게 배치합니다. 가중치·최대 개수·시드(배치 섞기) 지원.
- **채울 건물**: 리스트 전체 / 패널에서 체크한 항목만.
- **직접 놓기**: 목록에서 이름을 고르고 지도에서 Shift+클릭 → 가장 가까운 도로에 붙여 놓음. Shift+오른쪽 클릭으로 지움. "빈자리 채우기"를 끄면 직접 놓은 것만 짓습니다.
- **내부 도로 생성**: 깊은 영역에 건물 두 줄이 등을 맞대는 간격으로 도로를 깔고, 끝은 기존 도로에 연결, 긴 블록엔 가로 도로 추가. 안 될 때는 필요한 깊이를 숫자로 안내.
- **기존 건물 피하기**, **경계 자동 연석 맞춤**.
- **꼭짓점 맞춤**: 연석·교차로 모서리·도로와 평행/직각·8m 길이 단위. 게임 기본 맞춤 툴바를 빌더 패널 안에 그대로 넣었습니다.
- **게임 내 패널**: 왼쪽 위 버튼 또는 단축키 **Ctrl+Shift+B**(옵션에서 변경 가능). 리스트 선택, 건물 목록, 옵션, 섞기/영역 지우기, 진행 상황과 오류 안내.
- **리스트(팔레트)**: `ModsData/BlockBuilder/palettes/*.txt` 텍스트 파일. 옵션의 필터(용도·테마·필지 크기·출처·이름)로 만들 수 있고, 처음 실행 시 기본 리스트 2개가 생깁니다.
- **Anarchy 연동(선택)**: Anarchy가 설치돼 있으면 빌더 도구를 Anarchy에 등록합니다. Anarchy가 켜져 있을 때만 "겹침 허용(0~8m)"이 적용되어 필지가 옆·뒤로 겹칠 수 있습니다(도로·앞면은 겹치지 않음).
- 성장형 건물은 Plop the Growables와 함께 쓰는 것을 전제로 합니다.

## 구조

| 경로 | 내용 |
|---|---|
| `Core/` | 게임과 분리된 순수 C# 배치 엔진(배치, 도로 생성, 경계 맞춤, 꼭짓점 맞춤, 카탈로그 분류·필터, 리스트 형식) |
| `Core.Tests/` | xUnit 테스트 (`dotnet test`) |
| `BlockBuilder/` | 게임 연결: 도구(`BuilderTool`), 카탈로그 스캔, 설정·로케일(EN/KO), 패널 바인딩(`BuilderUISystem`), Anarchy 연결, 기술 검증용 Spike 도구 |
| `UI/` | React 패널 (게임 UI 모드 템플릿 기반) |
| `DESIGN.md` | 설계와 검증 기록, 테스트 순서, 남은 일 |

## 빌드

필요: Cities: Skylines II 공식 모딩 툴체인(`CSII_*` 환경 변수), .NET SDK, Node.js 18+.

```sh
cd UI && npm install        # 처음 한 번
cd ../BlockBuilder && dotnet build -c Release
```

`dotnet build`가 모드를 `%LocalLow%\Colossal Order\Cities Skylines II\Mods\BlockBuilder`에 배포하고, 이어서 UI도 빌드합니다(배포 단계가 폴더를 지우기 때문). 게임이 켜져 있으면 DLL이 잠겨 배포가 실패합니다.

엔진 테스트:

```sh
cd Core.Tests && dotnet test
```

## 로그

`%LocalLow%\Colossal Order\Cities Skylines II\Logs\BlockBuilder.log` — 계획 크기, 적용/차단 사유(오류 종류별 개수), Anarchy 연결 상태.
